# Logo — needed

The official **IEEE VGEC Student Branch** logo goes in this folder.

- Preferred: `ieee-vgec-sb-logo.svg` (SVG, transparent background)
- Otherwise: `ieee-vgec-sb-logo.png` (at least 512px wide, transparent background)

Until it's added, the header and footer can show a dashed "LOGO" box, as in the design.
Please don't use a logo downloaded from a random site. Get the official file from the branch core team.
